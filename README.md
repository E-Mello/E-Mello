# Hi, I'm Édio Mello 👋

### Senior Software Developer | Web Applications & Cloud Infrastructure

I design and build modern web platforms, combining robust software architecture, high-quality user experiences, and reliable cloud infrastructure.

My main focus is developing scalable applications with **Next.js and TypeScript**, from frontend architecture to backend APIs, deployment, observability, and production operations.

---

### What I work with

- **Frontend:** Next.js, React, TypeScript, Server Components, and modern UI architecture
- **Backend:** TypeScript, Node.js, Bun, REST APIs, authentication, and multi-tenant systems
- **Cloud & DevOps:** Docker, Linux, CI/CD, monitoring, and cloud deployments
- **Architecture:** Scalable web applications, API design, performance, security, and maintainable codebases
- **Databases:** PostgreSQL, relational modeling, migrations, and data-driven applications

I enjoy turning complex requirements into reliable products and helping teams make sound technical decisions throughout the entire software lifecycle.
